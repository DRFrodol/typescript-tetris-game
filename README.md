# Vector Blocks

A polished, browser-playable Tetris game built with TypeScript. Stack pieces, clear lines, and see how long you can keep the board alive.

## Run locally

```sh
npm install
npm run dev
```

Vite prints a local URL where you can play. To create and preview a production build:

```sh
npm run build
npm run preview
```

## How to play

| Action | Keys |
| --- | --- |
| Move | ← / → (or A / D) |
| Soft drop | ↓ (or S) |
| Rotate | ↑ / X (or W) |
| Hard drop | Space |
| Hold piece | C (or Shift) |
| Pause / resume | P (or Escape) |
| Restart after game over | Enter |

On small screens, use the touch controls below the board. The game includes a seven-piece randomizer, a ghost piece, a hold slot, a five-piece preview, level progression, and a locally saved high score.
